Key Features
============

✅ src/ + tests/ side-by-side in each package
✅ Separate Python versions (3.15 for app, 3.14 for parser)
✅ Shared database and models (in shared/)
✅ Independent deployment and scaling
✅ Clear import paths and dependencies
✅ Ready for microservices architecture

Running the Project
===================

Backend (Python 3.15):
  cd app/
  uv run --python 3.15 python -m uvicorn src.main:app --port 8000

Parser (Python 3.14):
  cd parser/
  uv run --python 3.14 python -m parser.src.scrapers.chicago_events_scraper

Frontend:
  cd frontend/
  npm run dev

Tests:
  pytest app/tests/
  pytest parser/tests/
  pytest shared/tests/

Database:
  Shared SQLite: data/events.db
  Used by: app/src and parser/src
  Models: shared/src/database/models.py
